## 1. Explain what Git is and how it differs from GitHub.

- git is a version control system that is used to track changes in files and project, it is installed in computer and used in CLI, with these it allows developers to save different version of their project using commits, create different branches, and manage the changes.

- GitHub on the other hand is an online platform that hosts git repositories, it allows to store git projects online and collaborate with teams more easily and efficiently through features like pull requests, code review, and issues.

basically git is a tool used to manage different versions of a project, while GitHub is an online platform where it houses git repositories, and can be shared with teams for collaborations.
