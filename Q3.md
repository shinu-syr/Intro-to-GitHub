3. Briefly explain the basic concepts of Git (e.g., repositories, commits, branches, pull requests, and merging).

- repositories are where project lives, and its version histories, this cna be stored locally or remotely on platforms like GitHub

- commit is a saved record of changes made tot he files in a repository, this usually mandates messages describing what changes before committing

- branch is a separate line of development or a copy of the existing code where it allows developers to work on changes, updates, without directly modifying the main branch

- pull requests is a request to merge the changes from one branch to another branch, it allows to review changes before any merging happens

- merge is the process of combining changes from one branch to another branch
